# 🎬 سيناريو العرض أمام لجنة التحكيم
# POC Demo Script (3–5 دقائق)

---

## المقدمة (30 ثانية)

**بالعربي:**
> "مرحباً بكم. نقدم لكم **بصير AI – الحارس الدلالي**: نظام ذكي يكتشف التناقضات المنطقية والدلالية في بيانات الاستبيانات **لحظياً أثناء الإدخال** — وليس بعد انتهاء الجمع الميداني. ما يميّز بصير هو أنه لا يراقب الناس فقط — بل **يراقب جودة الأسئلة نفسها** عبر الخريطة الحرارية الاستراتيجية."

---

## الخطوة 1: إدخال سجل متناقض (60 ثانية)

1. افتح Dashboard: `http://127.0.0.1:8501`
2. في تبويب **"إدخال الاستبيان"**:
   - العمر = **19**
   - سنوات الخبرة = **15**
   - التعليم = **PhD**
   - المسمى = **Doctor**
   - الدخل = **80,000**
   - المنطقة = **الرياض**
   - الحالة = **عاطل**
3. اضغط **"تحقق من البيانات"**

**ما يظهر:**
- 🔴 درجة الثقة تنخفض بشكل كبير (≈ 0–25)
- ⚠️ تحذيرات متعددة: خبرة > عمر، دكتوراه في 19، عاطل بدخل 80K
- 💡 توصيات ذكية: "نطاق الخبرة المقترح: 0-9 سنوات"
- 📝 سبب الدرجة: "3 مخالفة حرجة + 1 مخالفة متوسطة"
- 🤖 أو 📏 يظهر مصدر التحقق (LLM أو Rules)

**قل للجنة:**
> "لاحظوا أن النظام اكتشف فوراً أن شخصاً بعمر 19 لا يمكن أن يكون طبيباً حاصلاً على دكتوراه بخبرة 15 سنة وعاطل بدخل 80 ألف. **التنبيه لبق وإنساني** — ليس رسالة خطأ جافة."

---

## الخطوة 2: إدخال سجل نظيف (30 ثانية)

- العمر = **35**، الخبرة = **10**، التعليم = **Bachelor**
- المسمى = **Data Analyst**، الدخل = **18,000**
- المنطقة = **جدة**، الحالة = **Full-time**

**ما يظهر:**
- ✅ درجة الثقة: **100**
- لا توجد تناقضات

---

## الخطوة 3: لوحة التحليلات (60 ثانية)

1. انتقل لتبويب **"لوحة التحليلات والخريطة الحرارية"**
2. أشر إلى KPIs: إجمالي السجلات، نسبة الجودة، متوسط الثقة، زمن الاستجابة
3. أشر إلى جدول "أكثر الأسئلة تسببًا للأخطاء"

**قل:**
> "المشرف الميداني يرى لحظياً: كم سجل دخل، نسبة الجودة، وأي الأسئلة تسبب مشاكل."

---

## الخطوة 4: الخريطة الحرارية ⭐ (90 ثانية) — نقطة التميز

1. اعرض Heatmap:
   - بدّل بين المقاييس: العدد → النسبة % → متوسط الثقة
   - أشر إلى الخلية الأكثر حُمرة/كثافة
   - أشر إلى النجمة ⭐ على أكثر خلية إشكالية

2. اضغط **"عرض التفاصيل"** لخلية محددة:
   - يظهر Panel بأمثلة من السجلات الفعلية
   - يظهر نسبة التعارض ونوع المشكلة
   - يظهر **توصية إجراء**: "يُوصى بإعادة صياغة السؤال"

**قل:**
> "هذه هي نقطة التميز الحقيقية. الأنظمة التقليدية تكتشف أخطاء **البيانات** — بصير يكتشف أخطاء **الاستبيان نفسه**. السؤال رقم X في منطقة Y يتسبب بـ40% تعارضات — يعني السؤال محتاج إعادة صياغة قبل المسح القادم."

3. اعرض مخطط توزيع الأخطاء حسب المنطقة

---

## الختام (30 ثانية)

> "بصير AI يوفر ثلاث طبقات حماية: تنبيه للمستجيب، مراقبة للمشرف، وتحسين للاستبيان. النظام يعمل بالوقت الحقيقي، يدعم ربط LLM فعلي، ويقيس زمن الاستجابة. قابل للتوسع لأي نوع من مسوح الهيئة العامة للإحصاء."

## أوامر التشغيل السريعة قبل العرض

```bash
cd basseer_ai_poc
cp .env.example .env
# عدّل .env إذا أردت تفعيل LLM

python -m venv venv && source venv/bin/activate
pip install -r requirements.txt

# توليد + تشغيل
python scripts/generate_dataset.py
uvicorn backend.main:app --port 8000 &
sleep 2
python scripts/ingest_dataset.py
streamlit run dashboard/app.py --server.port 8501
```
